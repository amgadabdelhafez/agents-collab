# Routing in six rules

1. Driver owns the goal, decisions, repository writes and acceptance.
2. Nanny gets small independent reads, extraction, search and summaries. Direct
   gets deterministic profiled checks without paying a model to repeat a tool.
3. Au Pair gets cohesive evidence, bounded non-authoritative audits and small
   patch proposals, even with Codex as driver. Driver reviews and guarded-applies.
4. Send only useful separable work. Continue non-overlapping work while it runs.
   No packet quota; trivial, ambiguous or sequential work stays with the driver.
5. Reserve active patch scopes. On refusal fix a concrete shape error once or
   do the work directly. Never disguise edits as reads or repeat the same denial.
6. Configured aliases select approved models. Gateway owns provider retries and
   explicit fallbacks; Temporal owns durable work. No random model selection,
   inferred write authority or unknown pricing converted to zero.

Packet: objective + exact read/write scopes + kind/capabilities + acceptance.
Result: terminal state + evidence/patch + measured usage; not merely queued.
