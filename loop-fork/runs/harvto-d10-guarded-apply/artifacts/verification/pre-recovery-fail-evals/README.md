# Pre-recovery honest fail eval snapshot

These two files preserve the exact honest fail eval bytes produced after mandatory `test:ci`
attempts 13 and 14 each exited 1 with three rotating 5000 ms bridge-test timeouts. They were
snapshotted before standing recovery authority updated the canonical eval paths from the later
successful host-recovery bridge and serial certifications.

They remain historical failure evidence and are not current pass evals.
